# Universal Media Downloader

Chrome 116+. Використовуйте лише контент, на отримання якого маєте право. Розширення не обходить DRM, авторизацію чи контроль доступу.

## Встановлення

Розпакуйте архів у постійну папку. У `chrome://extensions` увімкніть режим розробника і завантажте папку з `manifest.json`. Для оновлення попереднього розширення використайте ту саму папку й натисніть «Оновити», щоб зберегти ID та налаштування.

У popup скопіюйте ID. У папці розширення відкрийте `browser-local` та запустіть `Install.cmd`. Підтвердьте реєстрацію для свого ID і завантаження yt-dlp. Інсталятор отримує автономний yt-dlp із офіційного GitHub, перевіряє SHA-256 і запуск. Після завершення натисніть «Перевірити підключення». Для оновлення копії host також повторно запустіть цей комплектний інсталятор після завершення активних завдань.

Native Host працює через штатний Windows PowerShell. Окремі Python, Node.js та FFmpeg не потрібні й не встановлюються. FFmpeg.wasm входить до пакета, не завантажується з CDN і запускається лише для потрібної обробки.

## Отримання медіа

Відкрийте публічну HTTP(S)-сторінку чи вставте URL. Детектор запускається при відкритті popup або кнопкою «Знайти медіа»: аналізує audio/video/source, прямі посилання, iframe та доступні ресурсні записи Performance API. Дублікати прибираються; імовірну рекламу позначено. Розміри з Performance API є приблизними, вони можуть бути відсутні або стосуватися лише переданого сегмента. `blob:` не є прямим завантажуваним файлом. Для чужих iframe без дозволу доступ обмежено: за наявності src можна передати посилання плеєра до yt-dlp. Постійного сканування та доступу до всіх сайтів немає.

Локальний режим використовує екстрактори yt-dlp для YouTube/Shorts, Vimeo, TikTok, SoundCloud та інших підтримуваних ним сайтів. Це не гарантує працездатності кожного конкретного URL. JS-середовища і віддалені компоненти yt-dlp вимкнені; якщо сайт вимагає їх, повертається помилка. Плейлисти не підтримуються як окремий груповий режим.

- **MP3:** 128/192/320 kbps, FFmpeg.wasm, назва та автор за наявності. Перевага окремому аудіо; якщо його немає, можливе отримання суміщеного джерела з вилученням лише звуку в браузері. Обкладинка може показуватися після аналізу, але не вбудовується у MP3.
- **Original Audio:** тільки доступний аудіопотік, без перекодування.
- **MP4:** натисніть «Аналізувати формати» та виберіть реально знайдений варіант. Готовий суміщений MP4 зберігається без обробки, коли його аудіо й відео підтверджено метаданими. Сумісні окремі потоки MP4/M4A об’єднуються через FFmpeg.wasm із stream copy і перевіркою обох доріжок. Якщо у готового файлу доріжки невідомі, їх перевіряє FFmpeg.wasm без перекодування. Несумісність і відсутність звуку не видаються за успіх.
- **Original Video:** найкращий суміщений вихідний файл або відеопотік без перекодування; відомий відеопотік без звуку позначається. Для прямого файлу з браузера наявність звуку додатково не перевіряється.

Для оригінальних прямих файлів автоматичний режим спочатку використовує Chrome Downloads. Інакше він обирає доступний локальний host. Запис вкладки є лише аудіорезервом після явного вибору; він працює у реальному часі, підтримує паузу й продовження та не потребує відкритого popup. Turbo раніше не був реалізований через втрату сигналу в прототипі; у цій версії не заявляється.

## Ресурси й обмеження

Одночасно виконується одне локальне завантаження й одна браузерна обробка. Черга, скасування та повтори збережені. Передавання Native Messaging йде порціями по 512 КіБ, проміжні фрагменти браузера зберігаються в IndexedDB. Після успішного збереження host прибирає джерела. Завантаження продовжується без вкладки та popup; для конвертації й експорту Chrome має працювати.

Конвертація/об’єднання та перевірка невідомого MP4 обмежені сумарним входом **64 МіБ**. FFmpeg.wasm потребує кількох копій у RAM; повністю потокове об’єднання гігабайтних файлів не реалізовано. Для великих файлів обирайте відомий готовий MP4 або Original Video. Оригінали передаються частинами, але їх експорт усе одно залежить від квоти й механізмів Blob браузера; багатогігабайтні файли не перевірено. Невідомі розміри можуть бути визначені лише після отримання потоків. За помилки вихідні тимчасові дані можуть залишитися для відновлення в `%LOCALAPPDATA%\YouTubeAudioBridge\jobs`.

Перевірено реальне отримання YouTube-аудіо, відеопотоку й аудіопотоку; MP3 та MP4 із двома доріжками через Chrome + Native Messaging + FFmpeg.wasm; детектор на HTML5-сторінці; відхилення відео без звуку та надмірного входу. Vimeo/TikTok/SoundCloud, DASH, усі роздільні здатності й багатогігабайтні файли окремо не перевірено. Прямі зовнішні MP4-джерела під час перевірки повертали HTTP 403; обходу не додано.
